ABOUT

Sakura Cinema is a website for browsing and booking Japanese animated movies. I chose anime because I enjoy watching it and wanted to use some of my favourite movies.

The website has five pages

- Home - Introduction to Sakura Cinema.
- Movies - Six movies with information and booking links.
- Recommendations - Suggests a movie based on user choices.
- Register - Account registration form.
- Booking - Ticket booking form.

DESIGN

I used an ivory background with dark green and grey colours. All pages have the same navigation and layout. CSS is used to adjust the website for smaller screens.

JAVASCRIPT

JavaScript is used for the registration and booking forms. It checks the information entered and displays errors if something is incorrect.

The booking page also calculates ticket prices, loads screening times from JSON, and shows different payment fields depending on the selected payment method.

The recommendation page uses if statements to suggest a movie based on genre, age group and viewing preference.

I used URL parameters to carry the selected movie from the Movies and Recommendations pages to the Booking page.
